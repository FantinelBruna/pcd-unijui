# Programação para Ciência de Dados

Repositório destinado às atividades, exercícios e projetos desenvolvidos na disciplina de **Programação para Ciência de Dados**, do curso de graduação da **UNIJUÍ – Universidade Regional do Noroeste do Estado do Rio Grande do Sul**.

## Tecnologias e ferramentas

Durante a disciplina poderão ser utilizadas ferramentas e tecnologias como:

* Python
* Jupyter Notebook
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Bibliotecas auxiliares para análise e visualização de dados
